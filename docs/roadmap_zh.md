# 研究路线

[首页](../README_zh.md) · [English](roadmap.md)

以下提出待验证的研究问题与实验设计。每项实验限定问题范围，并设置可检验正、负两种结果的对照。

## 方向一：模型基础

**接口变化下的校准。** 固定带标签状态，改变候选数、标签措辞、类别比例与问题类型。在独立验证集选择阈值，比较最大概率、前两项概率差和 API confidence，报告风险—覆盖率与校准，避免测试后挑有利阈值。

**状态是否足够。** 固定决策器，删除或扰动任务相关字段，配合规则和结构化 LLM 对照。观察哪些缺失事实造成错误，以及暂缓判断或补充观察能否识别这些情况，区分状态工程与模型改善。

**多模态证据与定位。** 固定原始场景和候选，对比文本状态、图像、裁剪图与图文联合输入。对缺失正确候选、错误前提、无法辨认和图外信息分别设计测试；控制选项数变化。用独立真值框评测 Box，并同时记录存在性门控的误拒绝、误接纳和完整任务表现。

**训练与计算复用。** 在同一视觉基座上分开比较原模型／LoRA，与独立串行／批处理／前缀复用。冻结权重检验执行优化；固定执行方式检验训练效果，分别报告单题延迟、整批吞吐和显存。

## 方向二：Agent 应用

**证据筛选。** 固定检索文档，分别判断主题相关性与是否支持结论；在相同预算下测量关键证据召回、错误支持和最终回答质量，检索器与回答生成器保持不变。

**上下文保留。** 对相同工具历史比较近期截断、摘要与 Jev 保留策略，维持调用—结果结构。评测后续任务完成、重复工具工作，以及路径、要求和未解决错误的丢失，而不只看 token 减少。

**计算路由。** 比较始终调用强模型、固定规则、小型结构化选择器和 Jev，固定工具与回退语义，在独立任务上记录误路由及所有辅助成本。

## 方向三：具身智能

| 研究 | 固定部分 | 改变部分 | 主要结果 |
| --- | --- | --- | --- |
| 执行纠错 | 感知、生成器、控制器与初态 | 复用／观察／重规划策略 | 成功、恢复、错误继续、总耗时费用 |
| 主动观察 | 检测器、候选视角与运动规划 | 下一视角选择器 | 目标准确率、最终成功、观察与运动预算 |
| 按需预测 | 动作候选、预测器与预测后排序 | 预测触发条件 | 匹配成功率或风险时的总计算 |

[具身导读](embodied_zh.md)提供更具体协议。最初可以用仿真检验实验机制，学习预测器与真实机器人的结论仍需单独评测。

## 可执行顺序

1. 比较前公开接口与评测协议。
2. 用小开发集发现日志、感知和执行问题。
3. 冻结配置，在配对初态与独立测试集上评估。
4. 连同失败、中断一起公开尝试记录，并保留各自协议标记。
5. 只有证据支持的范围才进入资源索引结论。

识别缺失观察或找到更强规则，也能改善系统，不必预设 Jev 一定胜出。
