# 模型基础：从接口到可靠判断

[首页](../README_zh.md) · [English](foundations.md)

Jev 通过托管 API 提供类型化判断。程序提供待判断内容与问题，模型返回选项、评分、命题概率或图像中的目标位置。本节介绍接口语义、置信度、基础评测及其与社区实现的关系。

TypeSafe 的 System One 命名借用“快思考”概念，强调快速判断；这不是公开的模型架构定义。官方 2026-09-15 发布说明介绍了专用架构、并行采样与 RLCD，但完整训练配方和官方模型权重仍未公开。

## 状态与独立问题

State 可以是文本、对象或数组。应包含能够改变答案的事实：任务、当前观察、可用候选、近期结果与观测时间；将这些事实与问题指令分开。同一请求中的所有问题读取相同状态、独立求值（[官方说明](https://docs.typesafe.ai/concepts/state)）。

可以批量提交独立问题以减少网络往返。如果先选物体会改变后一个动作问题的含义，应先确定物体，或构造物体—动作联合候选；不能假设同批某题的答案自动进入另一题。

State 还可通过 `assets` 引用图像，图像也能进入 `instructions` 与 `criteria`。官方文档明确：**Jev 1.13 和 1.14 均支持图像，Box 需要 1.14**。旧案例使用文本或结构化观察，是具体系统的实现选择，不是版本模态上限。[多模态导读](multimodal_zh.md)说明启用方式与输入限制。

## 四种判断类型

| 接口 | 语义 | 适用问题 | 设计风险 |
| --- | --- | --- | --- |
| Choice | 选项及预定义候选上的概率 | 工具、路线、目标、动作 | 正确候选可能根本未提供 |
| Score | 有序等级分布与等级索引的期望 | 进展、相关性、紧急性 | 等级可能混合不相容的维度 |
| Noul | 二值命题为真的概率 | 是否保留证据、条件是否满足 | 阈值可能无法迁移 |
| Box（1.14，实验能力） | 单个目标的归一化边界框与 confidence | 图像中的物体或区域定位 | 目标不存在也返回框，需要存在性校验 |

Score 使用从零开始的等级索引，分数为 `Σ i × pᵢ`。等级之间的距离是一种建模约定，1.5 分并不会自然成为客观物理量。Noul 的暂缓判断区间由程序定义，接口本身没有额外的“未知”答案。

参考：[Choice](https://docs.typesafe.ai/primitives/choice)、[Score](https://docs.typesafe.ai/primitives/score)、[Noul](https://docs.typesafe.ai/primitives/noul)、[Box](https://docs.typesafe.ai/go/box)。

## 客户消息示例

客户消息示例以“Stripe 连接失败三天，影响销售，请尽快处理”的英文消息同时提出部门 Choice、不满程度 Score 和紧急性 Noul。2026-10-27 的演示响应为 `jev-1.14.0`：技术支持概率 `0.81`、Choice confidence `0.72`；不满 Score 为 `1.0`、confidence `1.0`；紧急 Noul 为 `0.99`。

这些是单次演示记录的转录，用于说明响应结构，不构成准确率评测。完整题干、候选和响应转录见 [JSON 记录](../data/demo-records.json)。

## Confidence 是概率分布的统计量

官方定义的 Choice confidence，在候选数 `n > 1` 时为：

```text
confidence = (p_max - 1/n) / (1 - 1/n)
```

三个候选、最大概率为 0.85 时，结果为 0.775。最大概率、前两项概率差与 API confidence 是不同统计量；门控实验必须写清使用哪一种。

Score confidence 还考虑其他等级与最可能等级的距离。令 `m` 为最可能等级、`n` 为等级数，官方公式为：

```text
D = (1/n) × Σ |i - (n-1)/2|
Score confidence = max(0, 1 - Σ pᵢ × |i-m| / D)
```

Noul 没有独立 confidence 字段；程序可按官方建议自行计算 `|2p-1|`。这是派生统计量，不是额外模型答案。Box 的 confidence 需按定位任务单独验证，不应套用 Choice 公式。若要跨类型使用同一阈值，应先核对[官方定义](https://docs.typesafe.ai/confidence)。

分布集中不意味着答案正确。选择性预测需要同时观察错误率、回答覆盖率、回退成本与完整任务完成率。阈值在验证集确定，再冻结到测试集，不能看完测试结果再挑最好的门槛。

## 公开技术信息到哪里为止

[官方发布说明](https://typesafe.ai/blog/introducing-system-one-models-and-jev)提到专用架构、并行采样与 RLCD（Reinforcement Learning for Calibrated Decisions）。这些属于官方技术描述，尚不构成可独立复现的完整架构、训练配方或开放权重。接口行为与应用性能可以独立于未公开训练细节来研究。

类型约束能避免部分格式错误，却不能保证选中的标签符合事实或任务目标。生成式 LLM 也支持结构化输出，因此合理基线应采用可比较的答案约束。

## 两类性能证据

| 来源 | 测量什么 | 怎样解读 |
| --- | --- | --- |
| TypeSafe 发布时的工作流自测 | 与参考模型概率的一致程度、工作流成本 | 官方设计的工作流；一致率不能直接充当普遍准确率 |
| [37 数据集独立评估](https://arxiv.org/abs/2609.37647) | 分类评分质量、校准、选择性预测与 API 开销 | 独立预印本；对应指定版本、固定提示与基线 |

独立论文报告：对比 Qwen3.8-27B，Jev 在 37 项数据集中 27 项领先、9 项落后、1 项持平；领先项中有 11 项的 95% bootstrap 区间不重叠。这描述的是该评测设置，对照使用受约束评分、未启用思维链，不能直接外推到新任务。

官方发布时报告响应时间为 70–500 ms，2026 年 9 月输入价格为每百万 token 0.042 美元；独立论文在 32 路并发下报告平均客户端延迟 0.36 秒。环境、统计量与工作负载不同，不能据此计算通用加速倍数。历史价格也不是当前计费承诺。

延伸阅读：

- [图像输入与 Box](multimodal_zh.md)：官方多模态接口、缺失候选与证据不足的实例、48 张图的社区 COCO 评测。

1. 明确目标行为与可观测成功标准。
2. 只用决策当时可获得的信息构造状态与候选。
3. 在相同输入上比较规则、结构化 LLM 与 Jev。
4. 独立验证阈值及回退策略。
5. 执行判断后测量完整任务。
